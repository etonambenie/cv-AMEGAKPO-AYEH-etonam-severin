# CV & Portfolio en Ligne Cinématographique — AMEGAKPO-AYEH Etonam Séverin

Vitrine personnelle et portfolio digital haute-fidélité développé selon le standard créatif **Preset A — Architecte Minimal**.

## 🎨 Caractéristiques & Direction Artistique

- **Direction :** Architecte Minimal (Épuré Professionnel)
- **Palette :** Encre (`#1C1C1E`), Corail (`#E8634A`), Neige (`#FAFAFA`), Graphite (`#2D2D2D`)
- **Typographie :** 
  - Titres : *Plus Jakarta Sans*
  - Dramatique & Titres éditoriaux : *Cormorant Garamond* (Italique)
  - Données chiffrées & tags : *IBM Plex Mono*
- **Animations & Micro-Interactions :** GSAP 3 & ScrollTrigger avec transitions fluides, morphing de la Navbar au défilement, jauges circulaires de compétences animées et effets magnétiques au survol.
- **Texture Visuelle :** Filtre SVG inline `feTurbulence` (grain subtil) et courbures `rounded-[2rem]` à `rounded-[3rem]`.

---

## 🚀 Démarrage Rapide

Pour lancer le site en local :

```bash
npm run dev
```

Puis ouvrez votre navigateur à l'adresse indiquée (généralement `http://localhost:5173`).

Pour compiler pour la production :

```bash
npm run build
```

Les fichiers prêts à être hébergés (Vercel, Netlify, GitHub Pages, etc.) se trouveront dans le dossier `dist/`.
